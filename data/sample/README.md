# البيانات التجريبية (Sample Data)

> ⚠️ كل البيانات هنا **اصطناعية بالكامل** لشركة وهمية ("متجر النيل") —
> مخصصة للتطوير والاختبار فقط، وليست بيانات حقيقية.

## المحتويات

| الملف | الوصف |
|---|---|
| `documents/` | 4 مستندات عربية (سياسة الاسترجاع، دليل المنتجات، أسئلة الشحن، نبذة الشركة) — تُستخدم لاختبار الاستيعاب والتجزئة والاسترجاع |
| `customers.json` | 6 ملفات عملاء بصيغة `CustomerProfile` — شرائح متنوعة ومستويات churn مختلفة |
| `tickets.json` | 5 تذاكر بصيغة `Ticket` — قنوات وحالات وأولويات متنوعة |

## الاستخدام

```bash
# التحقق من سلامة البيانات مقابل العقود
python scripts/validate_sample_data.py
```

## للمطورين

- البيانات مطابقة لعقود `backend/models/` (v1) — أي تغيير في العقود يتطلب تحديثها.
- لإضافة بيانات جديدة: التزم بنفس الصيغ، وشغّل سكربت التحقق.
- البيانات الحقيقية لاحقًا توضع في `data/raw/` (مستبعدة من git) — هذا المجلد للعينات فقط.
