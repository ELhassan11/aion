# AION — Autonomous Intelligence & Organizational Knowledge Network

منصة ذكاء اصطناعي مؤسسي (Agentic AI) تحوّل البيانات والمعرفة المبعثرة داخل المؤسسات
إلى "عقل رقمي" قادر على الفهم والبحث والتحليل والتخطيط والتنفيذ والتحقق —
مع إشراك الإنسان في القرارات الحساسة.

> Understand → Retrieve → Reason → Plan → Act → Verify

## هيكل المستودع

| المجلد | المحتوى | الدور المالك |
|---|---|---|
| `ingestion/` | استقبال البيانات من PDF/DOCX/XLSX/CSV وقواعد البيانات وAPIs | R3 + R4 |
| `rag/` | محرك الاسترجاع المتقدم: تجزئة، Embeddings، بحث هجين، Reranking، استشهادات | R1 |
| `agents/` | رسوم LangGraph: الوكلاء الثمانية وتنسيقهم واستدعاء الأدوات | R2 |
| `knowledge_graph/` | الرسم المعرفي (Neo4j): الكيانات والعلاقات وربطها بالمقاطع | R4 |
| `backend/` | واجهات FastAPI، المصادقة والصلاحيات، سجل التدقيق | R5 |
| `frontend/` | لوحة المتابعة التفاعلية وشاشات الموافقات والتقارير | R6 |
| `customer-intelligence/` | وحدة ذكاء العملاء: Customer 360، التذاكر، مؤشرات الفقد، المتابعة | R2 + R4 |
| `eval/` | مجموعة التقييم والمقارنات المنهجية والمقاييس | R7 |
| `docs/` | وثيقة SRS وخطة التنفيذ وأي وثائق تصميمية | R7 + القائد |
| `scripts/` | سكربتات مساعدة (تجهيز البيئة...) | الجميع |
| `tests/` | الاختبارات: `unit/<module>/` للوحدة و`e2e/` للتكامل | الجميع |
| `examples/` | أمثلة استخدام جاهزة للتجربة السريعة | الجميع |

## التشغيل السريع

```bash
# 1) انسخ متغيرات البيئة واملأها
cp .env.example .env

# 2) شغّل البنية الكاملة
docker compose up --build
```

## قواعد العمل

قواعد الفروع وطلبات السحب والالتزامات موثقة في [CONTRIBUTING.md](CONTRIBUTING.md) —
اقرأها قبل أول push. الخلاصة:

- فرع لكل مهمة باسمها: `p0-t01/setup-repo`
- كل مهمة = طلب سحب واحد، يراجعه عضو آخر، وممنوع تدمج طلبك بنفسك
- رسالة الالتزام تذكر معرف المهمة: `[P0-T01] ...`
- الأسرار والمفاتيح لا تدخل المستودع أبدًا (`.env` محلي فقط)

## الوثائق

- `docs/` — وثيقة متطلبات النظام (SRS) وخطة التنفيذ المعتمدة
- خطة التنفيذ هي المرجع لـ "من يبني ومتى"، ووثيقة SRS هي المرجع لـ "ماذا نبني"
