# Backend — الخادم

واجهات FastAPI التي تربط كل الطبقات، المصادقة والصلاحيات، سجل التدقيق،
ومالك «عقد الواجهات» الذي تتفق عليه الأدوار.

المالك: R5.

## الهيكل المقترح داخل المجلد

```
backend/
├── app.py              # نقطة الدخول وإنشاء التطبيق
├── routers/            # مسارات الـ API (نسخ، وكلاء، عملاء، تقييم...)
├── services/           # منطق الأعمال (يستدعي الوحدات الأخرى)
├── models/             # نماذج البيانات (Pydantic / SQLAlchemy)
├── core/               # إعدادات، أمان، اعتماديات مشتركة
└── tests/              # اختبارات الوحدة الخاصة بالخادم (أو في tests/unit/backend/)
```

القاعدة: الـ routers لا تحتوي منطقًا — المنطق في `services/`.
