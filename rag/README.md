# RAG — محرك الاسترجاع المتقدم

التجزئة الدلالية (Semantic + Parent/Child)، فهارس Embeddings ثنائية اللغة،
البحث الهجين (BM25 + متجهي)، توسيع الاستعلام، إعادة الترتيب (Reranking)،
ونظام الاستشهادات الذي يربط كل جملة مولدة بمصدرها.

المالك: R1.

## الهيكل المقترح داخل المجلد

```
rag/
├── chunking/            # التجزئة الدلالية وParent/Child
├── embeddings/          # بناء فهارس الـ Embeddings ثنائية اللغة
├── retrieval/           # البحث الهجين (BM25 + متجهي) والترشيح بالبيانات الوصفية
├── rerank/              # توسيع الاستعلام وإعادة الترتيب
└── citations/           # نظام الاستشهادات وربط المصادر
```

القاعدة: كل مرحلة تستقبل مخرج سابقتها — لا قفز بين المراحل.
